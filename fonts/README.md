# Bundled fonts

Latin variable WOFF2 subsets downloaded from Google Fonts on 2026-09-06.
The app serves these files locally; it makes no font-service requests.
Other glyphs use the system fallback fonts.

- Public Sans, 400–700 normal: https://fonts.gstatic.com/s/publicsans/v21/ijwRs572Xtc6ZYQws9YVwnNGfJ7QwOk1.woff2
- Newsreader, 400–600 normal: https://fonts.gstatic.com/s/newsreader/v26/cY9AfjOCX1hbuyalUrK4397yjIJFJpc.woff2
- Newsreader, 400–600 italic: https://fonts.gstatic.com/s/newsreader/v26/cY9CfjOCX1hbuyalUrK439vCjohCBJWxZA.woff2

Both families use the SIL Open Font License 1.1. Unmodified license copies are
included alongside the binaries. Upstream: [Newsreader](https://github.com/google/fonts/tree/main/ofl/newsreader)
and [Public Sans](https://github.com/google/fonts/tree/main/ofl/publicsans).
