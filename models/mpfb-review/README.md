# Authored MPFB head — appearance candidate

Generated locally in Blender 4.5.12 LTS using pinned MPFB source and MakeHuman
CC0 core assets. `head.json` records source hashes, per-component licenses,
export units and missing anatomy. `LICENSE.txt` contains the source assets'
CC0 dedication. MPFB's application code is not included in this directory.

The founder selected this head as the foundation on September 6, 2026,
accepting its appearance for continued development and later refinement.
The decision and exact GLB hash are recorded in
`docs/plans/2026-09-06-realistic-closure.md`. This is separate from the pending
anatomical and final visual reviews in the generated export metadata.

The visible surfaces have open eyes, brows, lashes and an authored skin
material. The normal map adds procedural microdetail, not measured skin pores.
The preview PNGs are Blender renders; the interactive review renders the GLB.

The asset is not anatomically calibrated. It has no dermis or fat volumes,
tarsal plates, canthal attachments, orbital supports or validated landmarks.
Its visible eye surfaces must not be treated as reviewed contact geometry.

Reproduction and verification instructions: `tools/blender/README.md` in the
repository. Source licensing: [MakeHuman license](https://static.makehumancommunity.org/about/license.html)
and [core asset pack](https://static.makehumancommunity.org/assets/assetpacks/makehuman_system_assets.html).
